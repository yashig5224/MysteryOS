# MysteryOS

AI-powered, domain-independent investigation platform.

## Core workflow
1. Create investigation
2. Define mystery/question
3. Upload dataset(s)
4. Inspect data profile
5. Detect anomalies
6. Discover patterns
7. Build relationships
8. Construct timeline
9. Rank evidence
10. Generate hypotheses
11. Ask AI Copilot questions
12. Produce explainable findings
13. Export report

## Repository
- `frontend/` — Next.js application
- `backend/` — FastAPI application
- `data/` — local development data
- `tests/` — test suites
- `docs/` — architecture and API documentation

Read `AGENTS.md` before modifying the repository.
